給老師：怎麼把 LadderLab 用在課堂

這個網站能做什麼

LadderLab 是給技術型高中「可程式控制實習」用的練習網站，以學校常見的三菱 FX3S 為準。學生在瀏覽器裡就能讀課、寫階梯圖或指令表、接模擬機台，送出後自動評分。不用安裝軟體，也不用帳號。

  • 上機前預習：先在模擬器把程式跑通，到實習工場只做接線、寫入和試車，機台時間省下來。
  • 作業：每一章都有自動評分的練習題，評分會說出錯在哪一秒、哪一個輸出。
  • 補救與自學：請假或進度落後的學生可以照課程地圖自己補上。
  • 檢定準備：氣壓乙級、工業配線乙級的 PLC 題做成模擬機台，可以一條一條驗收（檢定專區）。
  • LabVIEW 實務案例：W6～W21 每一課都有評分重點、常見錯誤和怎麼發現、課堂建議（實務案例教師版，可以列印）。
模擬器不能取代實機。實機要練的有接線、GX Works2 寫入與監看、量測和故障排除。網站負責讓學生帶著「已經會動的程式」走進工場。

8 週課表範本

這份範本每週 3 節，8 週共 24 節。課綱建議本科 3 學分，所以這 8 週只是學期的一部分，大約對應課綱主題 B～E 和一部分 F。請依學校節數和設備調整。課號照課程地圖。

怎麼收學生進度

網站沒有帳號，進度只存在學生自己的瀏覽器裡。

  1. 下課前，學生到課程地圖按「匯出進度」，會下載一個 LadderLab_進度_日期.json。
  2. 請學生把檔名改成「座號_姓名」，上傳到班級雲端資料夾或 Classroom 作業。
  3. 下次上課（或換電腦）時，按「匯入進度」選這個檔案就能接著做。
  4. 老師把全班的檔案一次拖進全班進度表，就會得到「學生 × 章節、練習題」的表格，可以複製到 Excel。LabVIEW 上位機課程的完成課數和 CLAD 模擬考最佳成績也會一起列出。檔案只在瀏覽器裡讀，不會上傳。
目前的限制：
  • 匯入會蓋過這個瀏覽器原本的進度，請不要在同一台電腦連續匯入多位學生的檔案。
  • 課堂小考可以用考試模式：把練習頁網址寫成 practice.html?exam=1#E10（題號換成要考的那一題），提示和「看參考解答」會隱藏，評分照常。這只是把按鈕藏起來，學生拿掉 ?exam=1 就能看到解答，所以要搭配現場監考。
  • 進度檔是學生端產生的，不能當作防作弊的成績證明。正式評量請以實機驗收為主。

網址用途沒放行會怎樣
gn2222252-cmyk.github.io網站本身（頁面和評分程式）打不開
cdn.jsdelivr.net（路徑 /pyodide/v0.26.4/）在瀏覽器裡執行 PLC 模擬器的 Python 環境（Pyodide），包含 .wasm 檔課文可以看，但模擬器、評分、練習都不能用

  • 瀏覽器要用新版的 Chrome 或 Edge（需要 WebAssembly）。
  • 第一次開模擬器要下載數 MB。有還原卡的電腦每次開機都會清掉快取，全班同時開時會比較慢，請學生上課一開始就先打開練習頁。
  • 還原卡也會清掉進度，請學生每次下課都匯出進度。
  • 網站只有在填「候補名單」時才會送出資料，練習和進度都不會上傳。

已知限制

模擬器照 FX3S 的指令和元件範圍設計，但不是完整的 PLC。不支援的指令、32 位元與高速計數器、變址、掃描時間、相鄰步共用計時器等差異，都整理在模擬器和 FX3S 實機的差異。程式要上實機前，請一定要用 GX Works2 轉換一次。

檢定題（E18～E25）照勞動部公開試題做成模擬機台。其中 E19～E21 的停電保持照檢定題常用的 FX3U 範圍，其他課程照 FX3S。

為什麼可以用模擬軟體上課

課綱本科的教學注意事項寫明，教師可製作影片、投影片、成品或「電腦模擬軟體的操作」，讓學生觀察輸出的實際運作狀態。課程手冊在本科的教學備註中也寫「可利用成品展示或電腦模擬軟體的操作」。
