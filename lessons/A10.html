3.8 ALT 與 ZRST：一個按鈕切換、一次清除

本課目標用 ALTP 做一鍵開關，用 ZRST 一次清一整段狀態。

ALT 是「交替輸出」：每執行一次，目標就反過來，ON 變 OFF、OFF 變 ON。一個按鈕按一下開、再按一下關，用它最簡單。 但 ALT 跟 INC 一樣，條件成立的每一圈都會執行。按住一秒就切換幾十次，所以要用脈衝版 ALTP（或前面先接 PLS）。 ZRST 是「區間清除」：ZRST M10 M12 一行就把 M10～M12 全部 OFF，也可以清 Y、S、D。異常、急停、換模式時常用它把一整段狀態清乾淨。

開始互動版：看示範、自己按、慢動作看掃描 ›

ALTP Y0：只在 X0 剛按下那一圈執行一次。 ALT Y1：X1 按住的每一圈都執行，Y1 每圈反過來，看起來是亂閃，放開時停在哪一邊說不準。 ZRST 的兩個元件要同種類，而且前面的編號要比較小。 工業配線乙級的「手動交替啟停」、「異常時清除所有狀態」都用得到這兩個指令。

這一課的程式（指令表）

LD X000
ALTP Y000
LD X001
ALT Y001
LD X002
SET Y002
SET Y003
SET Y004
LD X003
ZRST Y002 Y004

只執行這段程式 ›

重點整理

  • ALT 每執行一次反轉一次，要加 P 才是按一下切一次
  • ZRST 清一段同種元件
  • 異常、急停、換模式時常用 ZRST

常見錯誤：ALT 沒加 P，按一下切換了幾十次。

預測看看

X0 按一下放開、再按一下放開，Y0 是？

看答案

OFF　ALTP 每按一下切換一次：ON 再切回 OFF。

按 X2 再按 X3，Y3 是？

看答案

OFF　ZRST Y2 Y4 把 Y2、Y3、Y4 一起清掉，中間的 Y3 也包含在內。
