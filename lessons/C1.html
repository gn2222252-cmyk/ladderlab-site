6.3 雙軸並行：兩邊都到位才過關

本課目標寫出雙軸同時移動、兩邊都到位才換步。

兩座龍門可以在同一個步序內同時移動；各軸到位後各自停止，流程要等兩個感測器都成立才轉下一步。這種「會合條件」常用在雙軸同步。 看 S20：Y0 只在 X2 未到時輸出，Y1 只在 X3 未到時輸出。只到一邊時，S20 仍保持；X2 AND X3 同時成立才進 S21。

開始互動版：看示範、自己按、慢動作看掃描 ›

X2 左到位X3 右到位所在步序結果
OFFOFFS20兩軸都動
ONOFFS20左停、右繼續
OFFONS20右停、左繼續
ONONS21兩邊會合，才進下一步

這一課的程式（指令表）

LD M8002
SET S0
STL S0
LD X000
SET S20
STL S20
LDI X002
OUT Y000
LDI X003
OUT Y001
LD X002
AND X003
SET S21
STL S21
OUT Y002
LD X004
SET S0
RET

只執行這段程式 ›

重點整理

  • 同一步驅動兩軸，各自到位各自停
  • 換步條件是兩個感測器 AND
  • 只到一邊時停在這一步等

常見錯誤：用其中一軸到位就換步，另一軸還在移動就進下一個動作。

預測看看

開始後只有左軸到位（X2 ON），Y0（左軸移動）是？

看答案

OFF　LDI X002：左軸到了就停，右軸繼續。

同上，這時 S21（下一步）是？

看答案

OFF　AND X002、AND X003：兩邊都到位才過關。
