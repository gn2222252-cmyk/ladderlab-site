PLC 互動課程 · 第 6 章　整機設計：從需求到程式

6.2 回到雙龍門

本課目標在雙龍門的真實程式裡找到前面學的每一種結構。

現在你學的全部用在機台上了。這一課是右龍門放料這三步的縮小版，後面接 P9 的輸出段。 看懂結構：上半是步進，只決定「想做什麼」，寫到 M；下半像 P9，集中加互鎖才輸出到 Y。下降要在定位點 X2 才准（互鎖）。 看完這課，按上方「開機台程式」回到真正的梯形圖，點任何一條階梯，下方會解釋它現在卡在哪裡。

開始互動版：看示範、自己按、慢動作看掃描 ›

這一課的程式（指令表）

LD M8002
SET S0
STL S0
LD X000
SET S25
STL S25
OUT M54
LD X001
SET S26
STL S26
OUT T1 K10
LD T1
SET S27
STL S27
OUT M53
LD X002
SET S0
RET
LD M54
AND X003
ANI Y001
OUT Y000
LD M53
ANI Y000
OUT Y001

只執行這段程式 ›

重點整理

  • 上半是步進，只決定想做什麼，寫到 M
  • 下半是輸出段，集中加互鎖才到 Y
  • 點每一條階梯看它現在卡在哪

常見錯誤：直接從真實程式第一行讀到最後一行。先找分區，再看每區。

預測看看

按一下 X0，Y0（下降）是？（定位點 X3 是 ON）

看答案

ON　S25 要求下降 M54，輸出區再確認定位點 X3 和沒有上升命令，才真的輸出 Y0。

下降中離開定位點（X3 OFF），Y0 是？

看答案

OFF　步序只決定「想要」，輸出區的互鎖決定「准不准」。不在定位點不准下降。
