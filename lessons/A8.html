5.2 逾時與異常：機台的保命結構

本課目標替會等待感測器的步加逾時，做出會報警的機台。

問題：步進會一直等感測器。感測器壞了，就永遠停在這一步，機器也不會報警。 解法：在這一步放一個計時器當鬧鐘。進這一步就開始數，正常到位就離開，鬧鐘自動歸零；數完還沒到位，就是異常。 下面對照表逐行說明，按「▶ 播放示範」看正常和異常兩種情況。雙龍門的 P3、P8 是同樣結構。

開始互動版：看示範、自己按、慢動作看掃描 ›

程式白話
STL S20：OUT Y0、OUT T0 K30動作，同時鬧鐘開始數 3 秒
LD X1、SET S0到位就回待機，鬧鐘線圈斷電自動歸零
LD T0、SET M3鬧鐘響了：記下「異常中」
LD M3、ZRST S0 S59ZRST 是區間清除：S0～S59 全部關掉，所有動作停止
LD M3、OUT Y1異常燈亮
LD X2、RST M3按復歸，清除異常
PLF M15、SET S0異常剛解除那一圈，回到待機

重點整理

  • 進步就開始計時，正常到位就離開
  • 時間到還沒到位＝異常，鎖住警報
  • 異常要能復歸，而且要先排除原因

常見錯誤：步進一直等感測器，感測器壞了機台默默停住，沒有任何警報。

預測看看

按 X0 開始，到位感測器 X1 一直沒來，4 秒後 M3（異常）是？

看答案

ON　S20 裡的 T0 K30 是 3 秒鬧鐘，時間到就 SET M3。

異常後，Y0（動作輸出）是？

看答案

OFF　M3 用 ZRST 把所有步清掉，S20 不作用了，裡面的 OUT Y0 跟著 OFF。
