4.9 兩條流程同時跑

本課目標寫出並行分支與並行合併。

雙龍門的兩座龍門各做各的。步進可以分支：一個 SET 開兩步，就有兩個黃色方塊同時走，互不等待。這叫「並行分支」。 這就是機台 S0 按啟動後同時 SET S20、SET S40。兩邊都跑完，要「並行合併」才能回到 S0。 三菱 FX 的並行合併寫法是：連續寫兩個 STL（STL S22、STL S42），中間不夾任何指令。意思是 S22 而且 S42 都在作用中，這一段才執行；離開時兩步一起關掉。SFC 圖上就是那條雙橫線。 注意：反過來說，兩個 STL 中間如果什麼都沒寫，PLC 就會把它們當成合併。空的等待步要放在合併的位置，不要隨便夾在別的步前面。 如果用自保持寫，兩條流程的條件會纏在一起；步進各走各的，所以不打結。

重點整理

  • 一個條件 SET 兩步，兩條同時走
  • 合併：連續寫兩個 STL，中間不夾指令
  • 兩邊都到了才一起離開

常見錯誤：兩個 STL 之間不小心什麼都沒寫，被 PLC 當成合併。

預測看看

按 X0 後 2 秒，右邊的 S21 是？

看答案

ON　右邊 S20 1.5 秒就換到 S21；左邊 S40 要 3 秒，兩邊各走各的。

按 X0 後 3.5 秒（右邊已完成、左邊還沒），S0 是？

看答案

OFF　並行合併（連續 STL S22、STL S42）要兩邊都完成才回 S0；左邊 S41 還在跑。
