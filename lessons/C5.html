PLC 互動課程 · 第 6 章　整機設計：從需求到程式

6.1 完整程式範本：一支氣缸的取放機

本課目標看懂一份完整機台程式的分區結構，知道每一區該寫什麼。

前五章學的東西，真實機台會全部放在同一份程式裡。這一課是一台最小的取放機：氣缸下降 → 吸附 1 秒 → 上升，可以手動、自動、循環停止，下降或上升超過 3 秒沒到位就報警。 看階梯圖上的灰色標題：程式分成 P1～P6 六區，順序固定：初始化 → 模式 → 手動 → 自動 → 異常 → 輸出。手動和自動都只寫「請求」到 M，只有最後的 P6 能碰 Y，互鎖和限位集中在那裡。雙龍門的 P1～P10 就是同一個結構放大。 自己試：X4 切到自動、按 X0 啟動，它會一直循環；按 X3 停止，做完這一輪才停。切回手動，用 X5、X6 點動。

開始互動版：看示範、自己按、慢動作看掃描 ›

區做什麼對應的課
P1 初始化M8002 進待機步；需要時清掉斷電保持的資料4.2 步進、5.4 停電
P2 模式決定現在是自動還是手動，寫成一個 M 給後面用2.3 自保持
P3 手動手動按鈕只產生請求，模式不對就不產生5.5 手動點動
P4 自動步進：每步只寫做什麼、等什麼、去哪裡；每步有逾時計時器4.6 步序表、5.2 逾時
P5 異常與停止逾時鎖住異常、清步序、回待機；停止只記請求，一輪做完才停5.3 首發故障、5.7 循環停止
P6 輸出自動請求 OR 手動請求，再串限位與相反方向互鎖，最後才 OUT Y2.4 雙線圈、2.5 互鎖、5.8 輸出仲裁
為什麼要分區：出問題時你知道去哪一區找。Y 不動就看 P6 的條件；P6 的請求沒來，再往上看是 P3 還是 P4 沒發出。 為什麼手動和自動不直接寫 Y：兩邊都寫就是雙線圈；而且互鎖只要在 P6 寫一次，誰下命令都逃不掉。 自動運轉中切回手動，也當成停止請求：這一輪做完才停，不會停在半路。 真實機台還會多：原點復歸區、HMI 狀態區、異常碼 D 暫存器。結構一樣，只是每區變長。

這一課的程式（指令表）

;# P1 初始化：開機進待機步
LD M8002
SET S0
;# P2 模式：X4 ON 是自動，OFF 是手動
LD X004
OUT M10
;# P3 手動：只產生請求 M41／M42，不直接碰 Y
LDI M10
AND X005
OUT M41
LDI M10
AND X006
OUT M42
;# P4 自動：步進只決定想做什麼（M31 下降、M32 上升）
STL S0
LD X000
AND M10
AND X002
ANI M3
RST M1
SET S20
STL S20
OUT M31
OUT T0 K30
LD X001
SET S21
STL S21
OUT T1 K10
LD T1
SET S22
STL S22
OUT M32
OUT T2 K30
LD X002
ANI M1
SET S20
LD X002
AND M1
SET S0
RET
;# P5 異常與循環停止：逾時鎖住 M3，清掉步序；按停止或切回手動只記請求 M1
LD T0
OR T2
SET M3
LD M3
ZRST S20 S22
LD M3
PLF M15
LD M15
SET S0
LD X007
RST M3
LD X003
ORI M10
SET M1
;# P6 輸出：唯一能碰 Y 的地方，集中加互鎖與限位
LD M31
OR M41
ANI X001
ANI Y002
OUT Y000
LD S21
OR S22
OUT Y001
LD M32
OR M42
ANI X002
ANI Y000
OUT Y002
LD M3
AND M8013
OUT Y003

只執行這段程式 ›

重點整理

  • 順序：初始化 → 模式 → 手動 → 自動 → 異常 → 輸出
  • 手動、自動只寫請求到 M，只有輸出區碰 Y
  • 出問題從 P6 往上追：Y 的條件 → 請求 → 哪一區沒發出

常見錯誤：想到哪寫到哪，同一個 Y 在手動區、自動區各寫一次。

預測看看

手動模式（X4 OFF）按住啟動 X0 一秒，S20 是？

看答案

OFF　S0 的啟動條件串了 M10（自動模式），手動模式按啟動不會進自動步。

自動模式啟動後，按住手動下降 X5 一秒，M41 是？

看答案

OFF　P3 的手動請求串了 LDI M10，自動模式下手動按鈕不產生請求。
