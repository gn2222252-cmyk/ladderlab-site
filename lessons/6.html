PLC 互動課程 · 第 4 章　順序控制：步進 STL 與 SFC

4.2 步進（STL）：同一件事，不打結

本課目標看懂 STL 步進：每一步只寫做什麼、等什麼、去哪裡。

這就是這台機台用的「步進階梯圖」。把機器想成流程圖：每個方塊是一步，一次只有一步作用（黃色）。 怎麼看：S 是步。STL S20 的意思是「以下是 S20 這一步的內容」。第一步由 M8002 開機時 SET S0 進入。S0～S9 是流程開頭的初始步，一般步從 S20 開始，編號不用連續（S10～S19 留給 IST 指令的原點復歸用；FX3S 的一般步是 S20～S255）。 每一步只寫三件事：做什麼 → 等什麼 → 去哪裡。 為什麼不打結：① SET S 會自動關掉目前這一步，不用下一步回頭切斷；② 離開時這一步的 OUT 自動 OFF；③ 每一步只管自己，插一步只改一個跳轉。 在 GX Works2 裡，STL 畫成左母線上的一個接點，下面的階梯都掛在它後面；三菱還有 SFC 流程圖畫法，右邊那張就是。

開始互動版：看示範、自己按、慢動作看掃描 ›

這一課的程式（指令表）

LD M8002
SET S0
STL S0
LD X000
SET S20
STL S20
OUT Y000
LD X001
SET S21
STL S21
SET Y001
OUT T0 K20
LD T0
SET S22
STL S22
OUT Y002
LD X002
RST Y001
SET S0
RET

只執行這段程式 ›

重點整理

  • M8002 SET S0 進初始步
  • SET 下一步會自動關掉目前這一步
  • 離開步時，步裡的 OUT 自動 OFF

常見錯誤：忘了最後的 RET，後面的一般階梯被當成最後一步的內容。

預測看看

按一下 X0，1 秒後 S20（下降步）是？

看答案

ON　SET S20 之後，S0 自動關掉，現在在下降這一步。

按一下 X0，3 秒後 Y1（吸盤，用 SET）是？

看答案

ON　到下限進 S21，SET Y001 吸住；SET 不會因為換步而放開。
