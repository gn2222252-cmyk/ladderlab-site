5.3 首發故障：保留第一個異常碼，原因排除後才復歸

本課目標保留第一個異常碼，原因排除後才允許復歸。

多個感測器可能接近同時故障。故障碼若每圈都被後面的條件覆蓋，維修人員看到的就不一定是最先發生的原因。常見作法是 D220 為 0 才寫入故障碼；第一個故障寫入後，後續故障不覆蓋。 復歸要先清除故障來源，再按 Reset。若故障條件仍在，程式會再次記錄故障。此範例以 X0/X1 模擬兩種故障，以 D220 顯示碼、M3 表示警報鎖存。

開始互動版：看示範、自己按、慢動作看掃描 ›

條件D220M3 / Y0
沒有故障0OFF
A 先發生10ON
B 後發生仍是 10保持 ON，不覆蓋首發碼
A、B 都解除後按 Reset清成 0警報解除

這一課的程式（指令表）

LD M8002
MOV K0 D220
RST M3
LD X000
AND= D220 K0
MOV K10 D220
LD X001
AND= D220 K0
MOV K20 D220
LD> D220 K0
SET M3
LD X002
ANI X000
ANI X001
RST M3
MOV K0 D220
LD M3
OUT Y000

只執行這段程式 ›

重點整理

  • 故障碼為 0 才寫入，後面的不覆蓋
  • 維修看的是最先發生的原因
  • 復歸前先確認故障來源已解除

常見錯誤：每圈都寫故障碼，最後看到的是連鎖反應的結果，不是原因。

預測看看

先發生故障 A（X0），再發生故障 B（X1），D220 是多少？

看答案

10　每條都先檢查 D220 = 0 才寫，所以只記第一個發生的異常（首發故障）。

故障 A 還在，按 Reset（X2），M3 是？

看答案

ON　Reset 條件有 ANI X000、ANI X001：原因還在就不能復歸。
