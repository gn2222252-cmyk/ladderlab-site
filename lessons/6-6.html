4.5 步進的陷阱：OUT 和 SET、共用計時器、往回跳

本課目標避開步進的三個陷阱：OUT／SET 的差別、相鄰步共用計時器、往回跳的寫法。

步進大多很直覺，但有三條規則不知道就會寫出「偶爾怪怪的」程式（三菱程式手冊 JY997D16601 第 35 章）。 ①離開步時，步裡 OUT 的輸出會自動 OFF，SET 的會保持，要 RST 才關。本課 S20 用 SET Y0 讓氣缸 A 伸出，離開 S20 仍然伸出，到 S22 才 RST；伸出中指示燈 Y4 用 OUT，一進 S21 就熄。 ②相鄰的兩步不能用同一個計時器（手冊 35.1.7 節 p.763）：轉移那一圈計時器線圈不會斷，現在值不歸零，下一步一進來可能已經數完，條件立刻成立。不相鄰可以共用：本課 S21 和 S23 都用 T0，中間隔著 S22。這個錯在本站模擬器裡也看得到：到 E12 讓相鄰兩步都寫 OUT T0，步序會卡住不換。實機出錯的樣子不一定一樣（常見的是一進下一步就立刻又換步），但不管哪一種都是錯的寫法。 ③往回跳、跳步用 OUT S，往下一步用 SET S（手冊 35.2.4 節 p.788）。GX Works2 把 SFC 的跳躍箭頭轉成指令表就是 OUT S。本站前面幾課用 SET S0 回待機，在 FX 上動作相同，但要和 GX Works2 的 SFC 一致就用 OUT S。

規則對錯
要保持的輸出SET Y0 … 到別步 RST Y0以為 OUT Y0 離開步還會留著
計時器相鄰步用不同的 T；不相鄰可以共用S21、S22 都寫 OUT T0
往回跳OUT S0（和 SFC 一致）—（SET S0 在 FX 上也會動，但和 SFC 不一致）
STL 後第一個指令LD、SET、OUT …MPS（手冊規定不行）
同一個輸出可以寫在不同的步（任一步作用時就輸出）；但在同一步寫兩次、或步進區外又寫一次，就是一般的雙線圈。 轉移那一圈，前後兩步會同時作用一個掃描，所以不能同時 ON 的輸出，程式裡也要互鎖。 同一步裡，寫了一條「LD 接點 → 輸出」之後，後面就不能再寫沒有接點的輸出；要嘛移到前面，要嘛前面加 LD M8000。

重點整理

  • 離開步 OUT 自動 OFF，SET 要自己 RST
  • 相鄰步不能共用同一個計時器（手冊 35.1.7）
  • 往回跳、跳步用 OUT S，往下一步用 SET S

常見錯誤：相鄰兩步都寫 OUT T0，實機上第二步一進來就換步，好像沒停。

預測看看

按啟動後 2.5 秒（在 S21 前端停留中），Y4（伸出中指示，S20 用 OUT）是？

看答案

OFF　已經離開 S20，步裡 OUT 的輸出自動 OFF。

同一時間，Y0（A 伸出，S20 用 SET）是？

看答案

ON　SET 的輸出離開步也保持，到 S22 RST Y0 才關。
