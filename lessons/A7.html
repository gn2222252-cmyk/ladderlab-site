PLC 互動課程 · 第 4 章　順序控制：步進 STL 與 SFC

4.10 步進的選擇分支：OK 和 NG

本課目標寫出選擇分支：依條件只走其中一條。

上一課的並行分支是「兩條一起走」；選擇分支是「兩條只走一條」。 選擇分支：同一步寫兩條換步條件，依條件只走一條，例如檢測 OK 走出料，NG 走剔除。X1 代表檢測結果。

開始互動版：看示範、自己按、慢動作看掃描 ›

這一課的程式（指令表）

LD M8002
SET S0
STL S0
LD X000
SET S20
STL S20
OUT T0 K15
LD T0
AND X001
SET S21
LD T0
ANI X001
SET S22
STL S21
OUT Y000
OUT T1 K15
LD T1
OUT S0
STL S22
OUT Y001
OUT T2 K15
LD T2
OUT S0
RET

只執行這段程式 ›

重點整理

  • 同一步寫兩個換步條件，條件要互斥
  • OK 走出料、NG 走剔除
  • 兩條最後都回到同一步

常見錯誤：兩個換步條件可能同時成立，結果兩步一起被 SET。

預測看看

檢測 NG（X1 OFF）時按 X0，2 秒後 Y1（NG 動作）是？

看答案

ON　1.5 秒檢測完，X1 OFF 走 S22（NG 那條路）。

檢測 OK（X1 ON）時按 X0，2 秒後 Y1 是？

看答案

OFF　選擇分支：X1 ON 走 S21（OK），NG 那條不會動。
