5.6 復歸與原點：清掉步序不代表機構已回原點

本課目標分清楚「程式回到待機」和「機構回到原點」。

PLC 的步序回到待機，只代表程式狀態被清理；龍門可能仍停在行程中間。要建立可信的原點，必須讓機構移動並由原點感測器確認。 本課用一個簡化軸示範：X0 開始回原點，Y1 朝原點方向移動；X2 是原點感測器。途中按 X1 只取消這次回原點，S20 關掉了，但 X2 仍 OFF，不能因此宣稱已原點。

開始互動版：看示範、自己按、慢動作看掃描 ›

觀察項目按取消後完成回原點後
步序S0 待機S0 待機
原點感測器 X2仍 OFFON
Y1 回原點輸出OFFOFF
是否確認原點否，軸可能還在中途是，感測器已確認

這一課的程式（指令表）

LD M8002
SET S0
STL S0
LD X000
ANI X002
SET S20
STL S20
OUT Y001
LD X001
SET S0
LD X002
SET S0
RET

只執行這段程式 ›

重點整理

  • 清步序只代表程式狀態
  • 原點要靠機構移動加原點感測器確認
  • 取消回原點後，原點還不算建立

常見錯誤：按復歸清掉步序就讓自動啟動，機構其實停在中間。

預測看看

按 Home X0，再按取消 X1，S0（待機）是？

看答案

ON　取消把步序清回待機。

這時原點感測器 X2 是？

看答案

OFF　步序回待機不代表機構回到原點，要原點感測器 ON 才算。
