4.4 步進的寫法規則

本課目標照固定規則寫 STL，知道 OUT 與 SET 在步裡的差別。

步進有固定寫法，照底下的規則寫就不會出錯。這一課的程式有三步：Y0 同時寫在 S20 和 S21，Y2 用 SET，看看離開步之後有什麼不同。

開始互動版：看示範、自己按、慢動作看掃描 ›

規則為什麼寫錯會怎樣
M8002 開機 SET S0～S9 的初始步開機時沒有任何步作用機器永遠不會動
S20 之類的一般步，由別的步 SET流程才是一條清楚的線步會亂跳，SFC 也轉不回來
步進區最後一定要 RET告訴 PLC 回到一般階梯程式錯誤，寫不進去
每一步：做什麼 → 等什麼 → 去哪裡固定順序，一看就懂邏輯難追，容易漏條件
同一線圈可寫在不同步同時只有一步作用平行分支同時作用的步不可共用
SET 的東西要自己 RST離開步只會關 OUT輸出一直留著
步裡不能用 MC／MCR手冊規定步裡不能用主控（程式手冊 35.1 節的指令表）轉換時報錯
轉移條件裡不用 ANB、ORB、MPS手冊規定轉移條件的電路不能用（35.1 節）轉換時報錯；複雜條件先算到 M，再用 M 當條件
步裡的 LDP、LDF 要小心步不作用時接點的變化抓不到，下次進這一步才被看到，可能一進步就跳走（35.1 節）莫名其妙連跳兩步；要即時抓邊緣，在 RET 後面用 PLS 做成 M 再用
一個分支最多 8 條並行或選擇分支最多 8 條，一個初始步底下的分支合計不超過 16 條（35.1.10 節）GX Works2 轉換錯誤

這一課的程式（指令表）

LD M8002
SET S0
STL S0
LD X000
SET S20
LD X002
RST Y002
STL S20
OUT Y000
OUT T0 K15
LD T0
SET S21
STL S21
OUT Y000
OUT Y001
OUT T1 K15
LD T1
SET S22
STL S22
SET Y002
LD X001
SET S0
RET

只執行這段程式 ›

重點整理

  • 同一個 Y 可以在不同步各寫一次 OUT（步進允許）
  • 步裡 SET 的輸出離開步不會關，要另外 RST
  • 換步用 SET Sxx

常見錯誤：在步裡 SET 了輸出卻沒有地方 RST，機台回待機時還在動。

預測看看

跑到 S22（SET Y2）後按 X1 回待機，Y2 是？

看答案

ON　SET 的輸出不會因為換步而 OFF，要另外 RST（本課用 X2）。

在 S21 時，Y0 是？（S20、S21 都寫了 OUT Y0）

看答案

ON　不同步各 OUT 同一個 Y 不算雙線圈：同一時間只有作用中的步會執行。
