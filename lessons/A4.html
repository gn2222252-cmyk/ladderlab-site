3.2 OUT、SET、RST、PLS、PLF

本課目標分辨 OUT、SET、RST、PLS、PLF 在「條件消失之後」的差別。

這五個是最常用的輸出指令，差別在「條件消失之後」。 OUT：條件在才 ON。SET：ON 了就鎖住，條件消失也不關。RST：把 SET 的東西關掉。 PLS：條件剛成立的那一圈 ON。PLF：條件剛消失的那一圈 ON。兩個都是「當圈」就 ON，寫在它下面的行這一圈就用得到。

開始互動版：看示範、自己按、慢動作看掃描 ›

INC D0：把 D0 加 1。　藍色方框：這一圈正在執行。 SET 方框綠色：輸出已被鎖住 ON。

這一課的程式（指令表）

LD X000
OUT Y000
LD X000
SET Y001
LD X001
RST Y001
LD X002
PLS M0
LD M0
INC D0
LD X002
PLF M1
LD M1
INC D1

只執行這段程式 ›

重點整理

  • OUT：條件在才 ON
  • SET 鎖住，要 RST 才關
  • PLS／PLF：剛 ON、剛 OFF 那一圈 ON

常見錯誤：用 SET 卻忘了寫 RST，或同一個元件既 OUT 又 SET。

預測看看

按一下 X0（按了放開），Y1（SET）是？

看答案

ON　SET 之後就保持，要 RST 才關。Y0 用 OUT，放開就 OFF。

X2 按住 1 秒，D0（PLS 加）是多少？

看答案

1　PLS 只在上升緣 ON 一個掃描，所以只加 1。
