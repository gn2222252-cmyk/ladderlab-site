5.9 操作面板：工作／復歸、單一／連續、急停

本課目標照檢定的操作面板，寫出工作／復歸、單一／連續、指定功能與急停的完整架構。

檢定和真實機台都有一塊操作面板：COS1 選「工作／復歸」，三段開關 COS2 選「指定功能／單一循環／連續循環」，一顆 ST／RST 按鈕，一顆急停 EMS（接常閉，斷線也等於按下）。燈號：綠燈待機、紅燈運轉、黃燈復歸中（0.5 秒閃）。這課用機電整合丙級的面板位址（X13～X17、Y15～Y17），搭一支雙線圈氣缸，把前面學的步進、循環停止、輸出仲裁、復歸組成完整的架構。 規則：①開機後要先復歸（M20 已回原點）才能啟動；②單一循環做一輪停在原點，連續循環一直做，運轉中按 ST 是「循環停止」，做完這一輪才停；③模式在啟動那一刻記在 M30，運轉中轉開關不影響這一輪（檢定題的「動作執行中切換功能無效」）；④急停時輸出全斷、步清回待機、M20 清掉；雙線圈閥（5/2 記憶型）斷電會保持最後的閥位，氣缸繼續走到行程底，解除後要重新復歸；⑤各步只寫「想要」的 M，輸出段集中加急停和互鎖。 注意：FX3S 的 S0～S127 停電保持，所以開機第一圈用 ZRST S0 S39 清步再 SET S0。 學校的 FX3S-20MT/ES 只有 X0～X13、Y0～Y7，沒有 X14～X17、Y15～Y17。在 20M 上照這個對照改位址：X0 前限、X1 後限、X2 COS1 工作、X3 指定功能、X4 連續、X5 ST、X6 EMS；Y0 伸出、Y1 縮回、Y2 RL、Y3 YL、Y4 GL。

面板做什麼程式怎麼寫
COS1 復歸＋ST回原點，黃燈閃S10 縮回；後限到而且 T1 滿 3 秒才 SET M20
COS1 工作＋單一＋ST做一輪停在原點S0 要 M20、X1；S22 看 M30 決定回 S20 或 S0
連續＋ST一直做；再按 ST 做完這輪停啟動時 SET M30；運轉中 ST 記到 M31
指定功能＋ST按一次走一個動作S30 伸出、S31 縮回，做完回 S0
EMS 斷開輸出全斷、要重新復歸ZRST S10 S39、RST M20；輸出段串 X17
這個架構就是氣壓乙級和機電整合乙、丙級共同的骨架：先寫面板和急停，再寫各模式的步序，最後集中輸出。 程式裡的急停只負責清步序、斷輸出；真正切斷危險能量的是急停迴路、安全電驛和接觸器，見第 5 章的「急停、安全迴路與硬體互鎖」頁。 單線圈閥斷電會回到彈簧側（常見是縮回，要看配管）；雙線圈閥（5/2）斷電保持最後的閥位，氣缸會走到行程底，不會中途停；要在中途停住要用 5 口 3 位置閥的「中位封閉型」（5/3 還有中位加壓型、中位排氣型，行為不同：中位加壓時兩側都有壓力，活塞桿可能因面積差慢慢動）；檢定題要求急停時夾住或吸住的工件不能掉，所以夾爪、吸盤要用能保持的接法。 機電整合丙級第 5 題規定連續中切回單一「有效」，那一題要改成每一圈都看 X15。

重點整理

  • 開機和急停後一定先復歸（M20），沒回原點不能啟動
  • 模式在啟動那一刻記住，運轉中轉開關不影響這一輪
  • 連續中按 ST 是循環停止，做完這一輪停在原點
  • 各步只寫 M，輸出段集中加急停和互鎖

常見錯誤：急停只斷輸出卻沒清步序和原點旗標，解除後機台從半路直接接著跑。

預測看看

開機後（工作模式）直接按 ST，Y0（伸出）是？

看答案

OFF　還沒復歸，M20（已回原點）是 OFF，S0 的啟動條件不成立。開機和急停後都要先復歸。

先切到復歸按 RST 等 4 秒，再切回工作按 ST，過 1 秒時 Y0（伸出）是？

看答案

ON　復歸完成 M20 ON，工作模式按 ST 進 S20，伸出中。
