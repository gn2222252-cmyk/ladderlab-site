4.3 步進和一般階梯圖差在哪

本課目標說出步進和一般階梯圖在執行上的差別。

兩種都是階梯圖，也都是合法寫法，差別在 PLC 這一圈要算哪些行。 一般階梯圖：每一條每一圈都算。步進階梯圖：程式切成一步一步，只有作用中的步才算，不作用的步不執行；RET 之後的一般階梯每圈照算。 精確一點說（程式手冊 35.1.2 節）：一步剛離開時，PLC 會把它當成「條件全部 OFF」再算一圈，所以這一步的 OUT 線圈變 OFF、一般計時器歸零；累計型計時器、計數器和 SET 的元件保持原狀，要自己 RST。之後這一步完全不執行，裡面的 MOV 這類指令也不做。換步的那一圈，前後兩步會同時作用。 下面程式上半是步進，最後一條是一般階梯。按「▶ 播放示範」看差別，底下是完整對照。

這一課的程式（指令表）

LD M8002
SET S0
STL S0
LD X000
SET S20
STL S20
OUT Y000
LD X001
SET S21
STL S21
OUT Y001
LD X002
SET S0
RET
LD X003
OUT Y002

只執行這段程式 ›

重點整理

  • 一般階梯每圈每行都算
  • 步進只算作用中的步；剛離開的步會用條件 OFF 再算一圈，OUT 變 OFF
  • RET 之後回到一般階梯

常見錯誤：把每圈都要算的東西（例如急停、互鎖）寫在某一步裡，那一步不作用就沒在算。

預測看看

還在 S0 待機時按住 X3（RET 後的一般階梯），Y2 是？

看答案

ON　RET 後面的一般階梯每個掃描都會算，不管現在在哪一步。

進 S20 後按 X1 換到 S21，Y0 是？

看答案

OFF　Y0 是在 S20 裡 OUT 的，離開 S20 就自動 OFF。
