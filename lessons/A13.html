5.4 停電：哪些東西會記住

本課目標知道停電後哪些元件會記住，並在 M8002 那一圈決定接著做或從頭來。

機台運轉到一半停電，復電後要「接著做」還是「從頭來」？這不是 PLC 自己決定的，是你寫的程式加上 CPU 的斷電保持範圍一起決定。 FX3S 跟很多教材用的 FX3U 不一樣：FX3S 的 S0～S127（S0～S9 初始步也保持）、M384～M511、D128～D255 預設斷電保持（存在 EEPROM），S20 這種一般步停電後還記得自己在哪一步。D0、M0 這些一般元件則會清成 0。 這一課的模擬照 FX3S 的保持範圍。按右邊的「⚡ 停電再復電」看看哪些東西留下來：步序 S21 留著、D128 留著、D0 歸零。

ANI S20

STL S22

SET S0

重點整理

  • FX3S 的 S0～S127、M384～M511、D128～D255 斷電保持，跟 FX3U 不同
  • 復電第一圈 M8002 ON：接著做就只在沒有步時 SET S0；從頭來就先 ZRST 再 SET S0
  • 輸出 Y 停電後一律 OFF，復電由程式重新決定

常見錯誤：照 FX3U 的寫法只寫 M8002 SET S0，在 FX3S 上復電後兩步同時作用。

預測看看

跑到第二段（S21）後停電再復電，Y1 是？

看答案

ON　FX3S 的 S21 斷電保持，復電後仍在 S21，Y1 再次輸出。

做完一輪（D0 = 1）後停電再復電，D0 是？

看答案

0　D0 是一般暫存器，停電清成 0；D128 才會保持。
