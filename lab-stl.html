輸送帶蓋章：待機按 X0 啟動 → S20 輸送帶走（OUT Y0），等工件到位 X1 → S21 推桿伸出（SET Y1），計時 1 秒 → S22 蓋章（OUT Y2），等蓋章完成 X2 → 回 S0。推桿要在待機時按 X3 才收回（RST Y1）。注意離開步之後 OUT 和 SET 的差別。

課文的兩句話在這裡都看得到：「換步的那一圈，前後兩步會同時作用」，所以不能同時 ON 的輸出（例如上升和下降）要另外加互鎖；「相鄰的兩步不能用同一個計時器」：轉移那一圈計時器線圈不會斷，現在值不歸零，下一步一進來可能已經數完。② 的結果是 S21 一進來就跳走；③ 在本站模擬器裡步序卡住、兩個燈一直同時亮。實機出錯的樣子不一定和模擬器一樣，但兩種都是錯的寫法：相鄰步請用不同的計時器。

兩座龍門同時動：S0 按 X0 後 SET S20、SET S30 同時開兩條流程。A 邊（S20 下降 1.5 秒 → S21 夾取 1 秒 → 等待步 S22），B 邊（S30 移動 4 秒 → 等待步 S31）。合流寫成 STL S22、STL S31 連在一起，兩步都作用才執行 SET S40；換步時兩步一起關掉。

復電後的第一圈 M8002 會 ON 一次，這一圈決定「接著做」還是「從頭來」。只寫 M8002 SET S0 的程式放到 FX3S 上，停電前在 S21，復電後 S21 還在，S0 又被 SET，就變成兩步同時作用。要接著做，就在 SET S0 前面加「沒有任何步在作用」的條件；要從頭來，就先 ZRST 清掉所有步再 SET S0。檢定題的停電要求每題不同，照題目寫。M8002 是 STOP→RUN 的第一圈，不只停電復電，寫入程式後切 RUN 也會 ON 一次。
