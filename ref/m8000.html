M8000：RUN 中常 ON

PLC 在 RUN 時一直是 ON。用在「每個掃描都要做」的指令前面。

語法可用元件
LD M8000唯讀

SFC 裡想讓某一步一進來就往下走，轉移條件可以寫 M8000。

相關的特殊元件（FX3 程式手冊第 37 章）：M8001 RUN 中常 OFF；M8003 第一個掃描 OFF、之後 ON；M8033 ON 時，RUN 切到 STOP 不清輸出和一般的 M、T、C、D；M8034 ON 時禁止全部輸出（程式照跑，實際輸出都 OFF）。

看門狗計時器 D8000：開機預設 200 ms，掃描超過就 ERR 燈亮、輸出全部 OFF；程式太長時可以 MOV K300 D8000 改大。D8010、D8011、D8012 是掃描時間的現在值、最小值、最大值（單位 0.1 ms）。

範例

LD M8000
OUT Y000

Y0 一直亮。
