三菱 FX PLC 指令說明

每個指令都有用途、語法、常見錯誤，還有可以直接在瀏覽器執行的範例。適用 FX3S 等 FX 系列（LadderLab 支援的指令）。

接點

LD：從母線接一個常開接點每一條階梯（或每一個區塊）的第一個常開接點。元件 ON 時導通。LDI：從母線接一個常閉接點和 LD 一樣是階梯的開頭，但接的是常閉接點：元件 OFF 時導通。AND：串聯一個常開接點（而且）在目前的條件後面串一個常開接點，兩個都成立才導通。ANI：串聯一個常閉接點（而且不是）在目前的條件後面串一個常閉接點：前面成立、而且這個元件 OFF，才導通。常用來寫停止和互鎖。OR：並聯一個常開接點（或）和前面的條件並聯，任何一個成立就導通。自保持就是 OR 自己的線圈。ORI：並聯一個常閉接點並聯一個常閉接點：前面成立，或這個元件 OFF，就導通。ANB：把兩個區塊串聯把前面兩個用 LD 開頭的區塊串在一起。在階梯圖上就是兩組並聯電路再串聯。ORB：把兩個區塊並聯把前面兩個用 LD 開頭的串聯區塊並在一起。LDP、LDF、ANDP、ORP：邊緣接點（按下或放開的瞬間）元件從 OFF 變 ON 的那一個掃描導通（P），或從 ON 變 OFF 的那一個掃描導通（F）。不用另外寫 PLS。

輸出

OUT：線圈輸出條件成立時線圈 ON，不成立時 OFF。用在 Y、M；接計時器、計數器時要加設定值（OUT T0 K30）。SET：設定（保持 ON）條件成立的那一刻把元件設成 ON，之後條件消失也保持 ON，直到 RST。RST：重置（清除）把元件設成 OFF；用在計時器、計數器時連現在值一起清 0；用在 D 時把數值清 0。PLS：上升緣脈衝（只 ON 一個掃描）條件從 OFF 變 ON 的那一個掃描，元件 ON；下一個掃描就 OFF。PLF：下降緣脈衝條件從 ON 變 OFF 的那一個掃描，元件 ON 一次。ALT（ALTP）：交替輸出（按一下 ON、再按一下 OFF）每執行一次，元件就反轉一次。一般用 ALTP：每按一下按鈕切換一次。MC、MCR：主控（一整段程式的總開關）MC 條件成立時，MC 到 MCR 之間的程式照常執行；不成立時，這段裡的 OUT 線圈全部 OFF、一般計時器歸零，SET 的元件和計數器保持原狀。

計時計數

計時器 OUT T：延時條件成立時開始計時，到設定值後 T 接點 ON；條件一斷，現在值歸 0。計數器 OUT C：數次數條件每從 OFF 變 ON 一次加 1，到設定值後 C 接點 ON 並保持，要 RST 才清除。

數值

MOV：傳送數值條件成立時把來源的值複製到目的地。常用來設定參數、切換步序號碼。BIN：BCD 轉成二進位（讀指撥開關）把 BCD 碼（每 4 個位元代表一位十進位數）轉成 PLC 計算用的二進位數。讀指撥開關一定要用它。BCD：二進位轉成 BCD（送七段顯示器）把 PLC 的二進位數轉成 BCD 碼，接到 BCD 七段顯示器（每位 4 條線）就能直接顯示十進位。ADD：加法來源 1 + 來源 2，結果放到目的。SUB：減法來源 1 − 來源 2，結果放到目的。INC：加 1條件成立的每個掃描把 D 加 1。CMP：比較並輸出三個結果比較兩個數，結果放在連續三個 M：大於、等於、小於各一個。比較接點 LD= LD> LD< …直接用兩個數的比較結果當接點：LD= D0 K5 代表 D0 等於 5 時導通。ZCP：區間比較判斷數值在區間下面、裡面、還是上面，結果放在連續三個 M。ZRST：區間整批清除把一段連續的元件全部清除，例如 ZRST S0 S59 把所有步關掉。SFTL／SFTR：位元移位（跑馬燈、工件追蹤）把一排連續的位元往高號（SFTL）或低號（SFTR）推 n2 格，空出來的位置由來源補進來。ROL／ROR：字組旋轉把一個 16 位元字組（D 或 K4M、K4Y）整個往左（ROL）或往右（ROR）轉 n 格，掉出去的位元從另一頭回來。脈衝型指令：MOVP、INCP、ADDP、DECP……指令名稱後面加 P：條件從 OFF 變 ON 的那一個掃描才執行一次。MUL：乘法（結果 32 位元）來源 1 × 來源 2，結果放在連續兩個 D（低位在前）。DIV：除法（商和餘數）來源 1 ÷ 來源 2：商放在 D，餘數放在 D+1。除以 0 不執行，並把錯誤旗標 M8067 ON。

步進

STL：步進接點（一步）STL S20 開始一段只有 S20 作用時才執行的程式。往下一步用 SET S21，往回跳或跳步用 OUT S，上一步自動關。RET：步進結束告訴 PLC 步進區到這裡結束，後面回到一般階梯圖。

特殊繼電器

M8000：RUN 中常 ONPLC 在 RUN 時一直是 ON。用在「每個掃描都要做」的指令前面。M8002：開機第一個掃描 ONPLC 從 STOP 切到 RUN 的第一個掃描 ON 一次。用來初始化、SET S0。M8013：1 秒時脈0.5 秒 ON、0.5 秒 OFF 一直重複。做閃爍燈最快。
