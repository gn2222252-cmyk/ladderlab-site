FX 指令說明 · 輸出

MC、MCR：主控（一整段程式的總開關）

MC 條件成立時，MC 到 MCR 之間的程式照常執行；不成立時，這段裡的 OUT 線圈全部 OFF、一般計時器歸零，SET 的元件和計數器保持原狀。

語法可用元件
MC N0 M100 … MCR N0N0～N7（巢狀層數）、M（主控接點）

常用在「手動模式區塊」「自動模式區塊」：模式不對，整段輸出一起關掉。

MC 和 MCR 的 N 編號要成對；巢狀時由 N0 往大編號用，MCR 從大的開始收回。

注意 SET 的輸出在主控 OFF 時不會被關掉，要另外 RST。

範例

LD X000
MC N0 M100
LD X001
OUT Y000
LD X002
SET Y001
MCR N0

X0 ON 時，X1 控制 Y0；X0 OFF 時 Y0 一定 OFF，但 Y1（SET）保持。

常見錯誤

  • 以為主控 OFF 會把 SET 的輸出也關掉。
  • 忘了寫 MCR，後面整個程式都被包在主控裡。
