ZRST：區間整批清除

把一段連續的元件全部清除，例如 ZRST S0 S59 把所有步關掉。

語法可用元件
ZRST 起點 終點FX3S 手冊：同一種元件的 Y、M、S、T、C、D，起點 ≤ 終點（程式手冊 12.1 節）。本站模擬器都支援；T、C 會清掉現在值和接點，和一個一個 RST 一樣

機台異常或急停時，常用 ZRST 一次清掉所有步序，再 SET 回待機。

開機時用 M8002 ZRST 清掉停電保持區的殘留資料。

ZRST Y000 Y007 一次關掉 Y0～Y7，急停或模式切換時常用。

範例

LD X000
SET M0
SET M1
SET M2
LD X001
ZRST M0 M2

按 X0 三個 M 都 ON；按 X1 一次全清。

常見錯誤

  • 起點和終點不同類（例如 M0 和 S10），轉換錯誤。
  • 起點寫得比終點大：實機只清起點那一個元件（程式手冊 12.1 節）；本站模擬器會直接報錯，提醒你寫反了。
  • 16 位元和 32 位元計數器不能放在同一個 ZRST 範圍（例如 ZRST C190 C210）。
