FX 指令說明 · 步進

STL：步進接點（一步）

STL S20 開始一段只有 S20 作用時才執行的程式。往下一步用 SET S21，往回跳或跳步用 OUT S，上一步自動關。

語法可用元件
STL S編號 … RETS（S0～S9 初始步，一般從 S20 起）

STL 和 SFC 是同一個東西：GX Works2 畫的 SFC 寫進 PLC 就是 STL 指令。

步裡用 OUT 的輸出，離開這一步就自動 OFF；不同步可以 OUT 同一個 Y。

連續兩個 STL（STL S22、STL S42）是並行合併：兩步都作用才執行。

換步的那一個掃描，前後兩步會同時 ON，相反動作要加互鎖。

往回跳（回到前面的步）、跳步用 OUT S，和 GX Works2 從 SFC 轉出來的寫法一致（程式手冊 35.2.4 節）；SET S 在 FX 上動作相同。

最後一定要 RET。

範例

LD M8002
SET S0
STL S0
LD X000
SET S20
STL S20
OUT Y000
LD X001
OUT S0
RET

按 X0 進 S20，Y0 亮；按 X1 回待機。

常見錯誤

  • 忘了 M8002 SET S0：一步都不會動。
  • 少了 RET：轉換錯誤。
  • 兩個 STL 中間沒寫東西，被當成並行合併。
