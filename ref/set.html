FX 指令說明 · 輸出

SET：設定（保持 ON）

條件成立的那一刻把元件設成 ON，之後條件消失也保持 ON，直到 RST。

語法可用元件
SET 元件Y、M、S

SET S20 是步進換步：在步進裡執行 SET S21，目前這一步會自動關掉。

吸盤、夾爪這類要跨好幾步保持的輸出，常用 SET，最後在別的步 RST。

範例

LD X000
SET Y000
LD X001
RST Y000

按一下 X0，Y0 亮了就一直亮；按一下 X1 才熄。

常見錯誤

  • SET 了卻沒有任何地方 RST，輸出永遠不會關。
  • 異常時沒有統一 RST，停機後還有輸出保持著。
