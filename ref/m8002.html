M8002：開機第一個掃描 ON

PLC 從 STOP 切到 RUN 的第一個掃描 ON 一次。用來初始化、SET S0。

語法可用元件
LD M8002唯讀

SFC 和 STL 一定要靠它（或啟動按鈕）SET 初始步，否則一步都不會亮。

也常用來清除停電保持區：LD M8002、ZRST D200 D254。

範例

LD M8002
MOV K5 D0
SET S0

開機後 D0 = 5，S0 ON。
