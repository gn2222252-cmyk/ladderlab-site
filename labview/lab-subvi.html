SubVI 實驗室：接線端、必要輸入、可重入

要做一個「讀 PLC 的 D 暫存器」的 SubVI。前面板有 7 個元件。先點左邊一個元件，再點右邊接線端（Connector Pane，4-2-2-4 樣式）的一格，就把它指定到那一格；再點一次那一格可以取消。下面的「呼叫端」會看到圖示長出對應的接腳。

    慣例：輸入在左、輸出在右；參考（VISA、Queue、檔案這類 refnum）放左上進、右上出；error in 左下、error out 右下。照這樣排，一串 SubVI 擺在一起時，參考線和錯誤線會變成兩條直線，從左穿到右，一眼就看得出順序。沒有指定到格子的前面板元件，呼叫端就接不到，等於 SubVI 內部自己用。

    SubVI「換算.vi」：結果 ＝ 原始值 × 倍率 ＋ 偏移。三個輸入各自可以設成 Required、Recommended 或 Optional（在 SubVI 的接線端那一格按右鍵 ▸ This Connection Is）。在呼叫端決定哪些有接線，按執行。

    Required：沒接線，呼叫端的執行箭頭就斷了，根本不能執行，用在「沒給就沒意義」的輸入（例如 VISA 資源、要讀的 D 編號）。Recommended：可以不接，Context Help 用一般字體列出，提醒你通常該接。Optional：可以不接，Context Help 用淡色。後兩種沒接時，SubVI 用的是那個控制元件存檔時的預設值（在 SubVI 前面板設好值，右鍵 ▸ Data Operations ▸ Make Current Value Default 再存檔），不是上一次呼叫傳進來的值。

    「慢讀.vi」裡面有 Wait 200 ms，還有一個沒接初始值的 Shift Register 當計數器：每被呼叫一次就加 1，並把新值傳出來。兩個平行迴圈 A、B 各呼叫它 3 次。切換 VI Properties ▸ Execution 的設定，按執行比較時間軸和計數器。

    Non-reentrant（預設）：記憶體裡只有一份，同一時間只讓一個呼叫者進去，另一個在門口排隊（斜線的部分）。兩個迴圈互相拖慢，但也因為只有一份，Shift Register 是大家共用的：A、B 的呼叫輪流把同一個計數器往上加。這正是 FGV（功能型全域變數）能在迴圈之間共用資料的原因，所以 FGV 一定要保持 Non-reentrant。
    Preallocated clone：方塊圖上每一個呼叫的位置都有自己的一份，可以同時執行，各自的 Shift Register 各記各的。適合「每台機器各自一個濾波器」這種需要獨立記憶的情況。
    另外還有 Shared clone：也能同時執行，但呼叫時借到的是哪一份不固定，所以不要靠它的 Shift Register 記東西。
