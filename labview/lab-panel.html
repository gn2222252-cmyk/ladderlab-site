人機介面設計工作室：讓前面板好看又好用

這是雙龍門機台的操作面板（簡化成 800 × 480）。一開始故意排得有點亂：先在 ① 自己整理，再到 ② 按「檢查」看建議。改過的版面會存在這個瀏覽器。用程式改顏色、反灰在 屬性節點實驗室，這一頁只談編輯時怎麼設計。

幾個操作：Label 是物件的名稱，前面板和方塊圖都看得到，執行中不能改；方塊圖、Event 結構、Local Variable 都用它認元件。Caption 是前面板上顯示的文字，方塊圖上不會出現，給操作員看的文字放這裡；執行中也可以用屬性節點改它。在元件上按右鍵 ▸ Visible Items 可以分別勾選 Label、Caption。上色工具點元件就上色；上色工具按住 Ctrl（Mac 用 Option 或 Command、Linux 用 Alt）會暫時變成吸管（Get Color），先吸一個元件的顏色，放開再點另一個元件，顏色就複製過去。顏色選盤右上角的 T 是透明；只想讓邊框透明，按住 F 再點 T。布林元件的 True、False 兩個狀態各有自己的顏色：先用操作工具把它切到要改的狀態，再上色。前面板背景（Pane）的顏色或圖片，講義的做法是在前面板捲軸上按右鍵 ▸ Properties ▸ Background。

檢查只看幾條有把握的通則：對齊、同類元件一樣大、顏色意義（紅＝停止／異常、綠＝運轉）、文字對比、重要按鈕的位置、有沒有重疊或太擠、Label 和 Caption 有沒有重複。點一條建議，面板上會把相關的元件框起來。

    對照本站的「控制盤」設計系統：運轉、啟動用綠（#127a3e），停止、異常用紅（#c62828），注意用琥珀（#b26a00），一般操作用中性灰；顏色只當輔助，按鈕上還是要有文字，色弱的人才分得出來。文字對比照 WCAG 的建議，一般文字至少 4.5 : 1。重疊和「太擠」用 8 px 當門檻，是本頁自己訂的。

    LabVIEW 的做法：在按鈕上按右鍵 ▸ Advanced ▸ Customize…，開出 Control Editor。工具列的扳手按鈕切到 Customize Mode 才能選到元件裡的零件；在零件上按右鍵 ▸ Import from File at Same Size… 換成自己的圖片（剪貼簿裡有圖時，也可以用 Import Picture from Clipboard）；做完選 File ▸ Apply Changes 套回原本的元件，或另存成 .ctl 自訂元件。下面模擬這個流程。

    自訂元件庫（.ctl）

    存成 .ctl 之後，在 Controls 選盤用 Select a Control… 選這個檔案，就能放到別的前面板。工具列的 Control Type 下拉選單決定它是 Control、Type Def. 還是 Strict Type Def.。三種都存成 .ctl，差別只在用到它的地方和這個檔案怎麼連結：Control 放上去之後就沒有連結；Type Def. 只同步資料型別，Strict Type Def. 連外觀一起同步，詳細比較在 Enum 實驗室：Type Def vs Strict。

      Tab Control 把畫面分成幾頁，讓自動、手動、異常紀錄各有一頁，不用全部擠在一起。點上面的頁籤切換；選一個元件，再選它要放在哪一頁。Tab Control 只是前面板上的容器：不管現在顯示哪一頁，每一頁上的控制項都在，方塊圖上所有端子都在，值照樣讀寫得到（虛線框的是目前畫面上看不到的元件，不是「沒在執行」）。Tab Control 自己的值是 Enum 類的，代表目前顯示哪一頁。這件事的完整動畫在 叢集實驗室：Tab Control。

      方塊圖上的端子（用 Label 顯示）

      在 Tab Control 上按右鍵可以 Add Page After、Add Page Before、Duplicate Page、Remove Page；右鍵 ▸ Advanced 裡有 Allow Multiple Colors，讓每一頁有自己的顏色。停止、急停這類按鈕不要放進某一頁：切到別頁就看不到，要放在 Tab Control 外面，每一頁都看得到的位置。

      題目隨機產生，選項順序也會打亂。答錯會看到解說，按「下一題」換一題。
