PLC 與上位機交握：命令、回應、上升緣、逾時

兩台各跑各的機器要合作，靠的是「我寫一個值，等對方回應，再收回」。左邊（或上面）是 LabVIEW 的迴圈，右邊（或下面）是 PLC 的 D／M；下面的時序圖把兩邊的每個訊號畫在同一條時間軸上。分頁 ① 和 ③ 用雙龍門專案（第 17 課、第 19 課）的位址，分頁 ② 用 13_PLC 檢測分選機（A5）的位址。

雙龍門的 PLC 每次掃描執行 LD> D106 K0 → MOV D106 K2M100 → MOV K0 D106：D106 不是 0，就把它搬到 M100～M104（Start、Stop、Home、Reset、Clear），同一個掃描就把 D106 清回 0，M10x 再取一掃描脈衝。所以 LabVIEW 這邊只要寫一次 D106 = 4，PLC 就會原點復歸一次。動畫把 PLC 掃描放得很慢，一格就是 PLC 掃描一次。

前面板：
第 0 格

「送達」有三層：① FX_WriteD 收到 ACK：PLC 收到封包、D106 已經寫進去（課文的做法，到這裡就算寫成功）；② 讀回 D106 = 0：PLC 的程式真的掃到了，把命令拿走；③ 機台真的動了（例如 D202 原點步序出現 10～13）。注意 ② 不等於 ③：PLC 拿走 Home 之後，還要「在 S0、沒有異常」才會開始原點；Start 還要自動模式、已原點。所以想知道命令有沒有「生效」，要看狀態（步序、異常碼），不是只看 D106。
PLC 在 STOP 時程式不掃描，D106 就一直停在寫進去的值。真機上 PLC 掃描是毫秒級、LabVIEW 每寫一筆都要等 ACK，「上一筆還沒被拿走就寫下一筆」平常很難撞到；動畫把掃描放慢只是為了讓你看見：D106 只有一格，沒被拿走前再寫一次，前一筆就被蓋掉了。

13_PLC 的 5 步交握：PLC 到步序 70，寫 D306 = 零件 ID、D302.b0 = 1（請求檢測）→ 檢測迴圈看到 b0 上升緣就檢測，寫 D510（結果）再寫 D511 = 1（完成）→ PLC 看到 D511 = 1，讀 D510，b0 = 0，往下走 → 檢測迴圈看到 b0 下降緣，寫 D511 = 0 → 下一顆。通訊迴圈每 100 ms 讀一次 PLC，用 Notifier 送給檢測迴圈；檢測迴圈的 Wait on Notification timeout 500 ms。一格 = 100 ms。

t = 0.0 s

為什麼要用上升緣：b0 = 1 會維持好幾圈（PLC 要等通訊迴圈把 D511 = 1 寫過去，才會把 b0 收回，再等下一圈讀回來）。用位準判斷，檢測完時通知裡的 b0 多半還是 1，同一顆就再檢測一次；而且 b0 = 0 的每一圈都寫一次 D511 = 0，寫入佇列一直有東西。上升緣只在「這圈 1、上一圈 0」那一圈成立一次。
為什麼要管 Timed Out：通知逾時那一圈，Wait on Notification 輸出的是預設值（全 0）。把它當成 b0 = 0，就會誤判一個下降緣；通訊恢復後第一筆通知又是 b0 = 1，變成新的上升緣，同一顆檢測兩次。課文的 Host_Edge 在逾時時保留上一圈的值（Next = Timed Out ? Prev : b0）。
相機斷線：檢測出錯，錯誤線讓後面的 Enqueue 都不執行，不寫結果；PLC 等不到 D511，逾時報 9005（課文 A5 的練習是約 5 秒，PLC 的檢測逾時參數是 D531）。

雙龍門的心跳是兩邊互相看門狗：LabVIEW 每秒把 D240 加 1（1～32767 循環）；PLC 用 T30 計時「D240 和上一次掃描一樣、而且大於 0」，3 秒沒變化就算 HMI 斷線。LabVIEW 這邊看的是通訊本身：VISA Read 等不到回應，逾時（課文是 2 秒）就出錯，下一圈進錯誤頁重連。通訊迴圈約 200 ms 一圈。一格 = 100 ms。先按 ▶ 讓它跑幾秒，再拔線。

各自的安全狀態（課文第 17、19 課，PLC 程式 P7、P8）：
PLC：T30 一到，「手動有效」M5 變 OFF，D107 清 0、M110～M125 全部 RST，點動馬上停；只有手動模式會報異常 40（因為這時 HMI 是唯一的操作站），異常要等 Reset 才清掉。自動模式不報 40。D240 = 0 代表「沒有 HMI」，PLC 不檢查，所以正常 Exit 先寫 D240 = 0 就不會報警；用 Abort 砍掉就沒寫到，手動模式 3 秒後報 40。
LabVIEW：錯誤頁做 Clear Errors → VISA Close → Wait 1000 ms → FX_Open 重開 → Flush Queue，把斷線期間累積的命令全部丟掉（舊的點動命令不能在重連後才送出去），PLC Connected 燈熄滅，程式不停。
13_PLC 用的是 D520、2 秒、警報 9006，想法一樣，數字不同。
