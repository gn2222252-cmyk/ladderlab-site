變數實驗室

兩個平行迴圈各自做三次「讀 x → 加 1 → 寫回 x」，x 用 Local Variable（或 Global Variable）共用。照理說最後 x = 6。你來當排程器：決定下一步讓哪個迴圈走。試著讓 A 讀完之後，換 B 也去讀。

共用的 x0Local Variable

這就是競爭條件（Race Condition）：結果取決於兩邊誰先誰後，而且每次執行可能不一樣，最難除錯。只要有兩個地方會「寫」同一個變數就有風險。安全的做法：只留一個地方寫（其他只讀）、或把「讀改寫」包進 FGV、或改用 Queue 傳資料。

兩個平行的 While Loop，想用一顆 Stop 按鈕同時停掉。這是 Local Variable 最常見的用途，也是最常接錯的地方。選一種接法，按 Stop 看會怎樣。

FGV 不是內建功能，是自己寫的 SubVI：一個只跑一圈的 While Loop（停止條件接 True）＋沒接初始值的 Shift Register＋一個 Case 選動作。Shift Register 沒初始化，就會記得上次呼叫留下的值；SubVI 預設不可重入，同一時間只讓一個呼叫者進去，所以「讀改寫」不會被插隊。

動作用 Enum（做成 Type Def）選：Init 把值設回起始值、Add 做「讀＋改＋寫」、Get 只讀。只做 Get／Set 的 FGV 和 Global Variable 一樣會有競爭條件；要把「改」的運算放在 FGV 裡面才安全（這種寫法也叫 Action Engine）。講義裡的計時器 FGV 也是同一招：Init 時記下 Tick Count，Get 時回傳現在減掉記下的值。
