Formula Node 實驗室

算式一長，用 Add、Multiply、Divide 一個一個拉線會變成一大片。Formula Node 讓你把公式直接打成文字，語法很像 C。這裡用雙龍門機台常算的四個公式，對照兩種寫法，再練習 Formula Node 的語法規則和整數除法。

圖形節點拉線

同一個控制項分岔出去的線，圖上為了清楚畫成好幾個方塊。

Formula Node

左邊框上是輸入變數、右邊框上（粗框）是輸出變數，都要在邊框上右鍵 Add Input／Add Output 宣告。

兩邊算出來一樣，差別在好不好讀、好不好改。四則運算加一兩個函式，圖形節點一眼看得懂；公式長、有 if/else 或要照著規格書抄公式時，Formula Node 比較清楚。Formula Node 裡面沒有線，不能在中間放探針（Probe）看中間值，要看就多拉一個輸出變數出來。

在框裡打 Formula Node 的內容，按「檢查」。這是用 JavaScript 做的簡化模擬：只認得一小部分語法（宣告、指定、+ − × ÷ %、比較、if/else、for、while 和幾個常用函式），用來練習 LabVIEW 最常擋下來的錯誤。

執行箭頭：➡
    規則：① 大小寫有分，x 和 X 是兩個不同的變數。② 每個敘述結尾要分號 ;。③ 輸入、輸出變數要在邊框上宣告；公式裡自己用的變數要先宣告型別，例如 int32 i;、float64 s;。④ 可以用 if / else、for、while，寫法和 C 一樣。⑤ 本模擬器認得的函式：sin cos tan sqrt abs exp floor ceil pow max min（LabVIEW 實際支援的更多，請看說明文件的 Formula Node 函式表）。語法錯了，LabVIEW 的執行箭頭會變成斷的，按下去 Error List 會指出是這個 Formula Node 有錯。

    右軸馬達一圈 10000 個脈波。PLC 回傳累積脈波數，想知道「轉了幾整圈、還多幾個脈波」，用的是整數除法。先用小數字看清楚：x 個東西，每 y 個一組。

    Divide（÷）

    x ÷ y = ? DBL

    兩個 I32 相除，輸出是 DBL 小數，不會自動變整數。

    Quotient & Remainder

    IQ = ? I32
    R = ? I32

    一次給「幾整組」和「剩幾個」，輸入是 I32，輸出也是整數。

    Formula Node

    q = floor(x / y); → ?
    r = x % y; → ?

    % 是取餘數。整數商用 floor() 包起來，意思最清楚。

    本頁只用 0 和正整數。遇到負數時，「往 0 截斷」和「往下取整」的結果會不一樣，Quotient & Remainder 和 Formula Node 的 %、整數 / 用的是哪一種，請以 LabVIEW 說明文件或自己實測為準。輸入限制 y ≥ 1，不示範除以 0。
