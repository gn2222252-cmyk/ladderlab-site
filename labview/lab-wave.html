DAQ 讀回來的資料多半是 Waveform：一串數字加上「從什麼時候開始、每點隔多久」。這裡看 Waveform 怎麼組合拆開，再對龍門機台的馬達電流、振動、溫度訊號做最常用的統計和移動平均。

右軸振動感測器，量了 25 點。Waveform 是一個特殊的叢集，三個主要元素：t0（第一點的時間戳記）、dt（每點間隔幾秒）、Y（量到的值陣列）。另外還能帶屬性（attributes），本頁不用。

dt 只是「標籤」：改 dt，Y 陣列一個數字都沒變，只是 Graph 的 X 軸刻度跟著放大縮小。dt 錯了，算出來的頻率、時間全部跟著錯，程式卻不會報錯。dt 的倒數就是取樣率：dt = 0.001 s 就是 1000 S/s。X 軸要顯示成時鐘時間還是從 0 起算的秒數，是 Graph 的 X 軸顯示格式設定（右鍵 ▸ 屬性 ▸ Display Format），本頁用下拉選單示意兩種看法。
訊號MeanMean ± 1σRMSMax／Min

RMS 和 Mean 只有在「平均是 0」的時候差很多：振動訊號平均是 0，但 RMS 告訴你它抖多大。有直流偏移時（例如馬達電流），RMS 會被偏移量拉大。兩者的關係：RMS² = Mean² + σ²（這裡的 σ 是除以 N 的母體標準差）。LabVIEW 的 Std Deviation and Variance VI 有 weighting 輸入，可以選 Sample（除以 N − 1）或 Population（除以 N），兩種本頁都列出來。標準差用 Std Deviation and Variance VI：weighting 沒接線時預設是 Sample（除以 N−1），接 1 才是 Population（除以 N）。

右軸馬達電流：第 40 點啟動（0.3 A → 3 A），第 100 點停止。電流計有雜訊。移動平均：每一點的輸出 = 最近 N 點的平均。在 While Loop 裡可以用 Shift Register 記住最近 N 點，或對整個陣列一段一段算。

N 越大，雜訊越小，但有兩個代價：① 變慢：電流已經跳上去了，平均值還要等視窗裡的舊點都換掉，N 點之後才完全跟上；② 邊緣變鈍：原本直上直下的變化被拉成斜坡。要看很快的變化（例如過電流保護），N 不能太大。
起頭的處理：本頁前 N−1 點只平均「已經有的點」。自己用 Shift Register 存最近 N 點時，如果陣列初始化成全 0，前 N−1 點會把 0 一起平均進去，數值會偏低。
