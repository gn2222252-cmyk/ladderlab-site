圖表實驗室

同一筆資料同時送給 Waveform Chart 和 Waveform Graph。Chart 會記住以前的點，新資料接在後面；Graph 不記，每次收到整包資料就整張重畫。選一種資料型別，按「送一次」，多按幾次看差別。

Waveform Chart

Waveform Graph

Chart 的歷史長度預設 1024 點（右鍵 ▸ Chart History Length 可改），滿了就丟掉最舊的。VI 停止再執行，Chart 上的舊資料還在，要自己 Clear 或用 Property Node 的 History Data 寫入空陣列。Chart 的三種更新模式（Strip、Scope、Sweep）動畫在 CLAD 第 11 課。

Waveform Graph 的 X 軸永遠是「等間隔」（0、1、2… 或 x0＋i×dx）。要畫圓、畫軌跡這種 X 會來回跑的圖，就要 XY Graph：把 X 陣列和 Y 陣列用 Bundle 包成一個叢集，同一個索引的 X[i]、Y[i] 配成一點，再依序連線。

XY Graph（接 Bundle(X, Y)）

同樣的 Y 陣列接到 Waveform Graph

XY Graph 接受兩種資料：① 叢集（X 陣列, Y 陣列），就是上面這種；② 「點」的陣列，每個元素是一個 (x, y) 叢集。畫多條線時，把每條線的叢集再用 Build Array 組成陣列。X 和 Y 陣列長度不一樣時，只畫到短的那個為止。
