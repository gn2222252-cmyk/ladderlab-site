檔案 I/O 實驗室

F1～F5 課學了「開檔 → 寫 → 關檔」。這裡用動畫看三件課文不容易想像的事：開檔方式遇到「有檔／沒檔」的結果、檔案裡那支看不見的寫入指標、還有 CSV 紀錄一行一行長出來的樣子。

要寫的檔案是 D:\雙龍門\log.csv。選 operation、決定檔案原本在不在，按「執行」。把 12 種組合都試過，下面的表就會填滿。

log.csv

      
Open/Create/
Replace File

      

    

    

    

    

    
一句話記：名字裡有 create 的，沒檔就建；名字裡有 replace 的，有檔就清空；只有 open 的保留內容。單獨的 open、replace 遇到沒檔都是錯誤 7；單獨的 create 遇到有檔是錯誤 10（重複路徑）。錯誤 8 是沒有權限或檔案正被別的程式占用。

  


  

    
每個開著的檔案都有一個「寫入位置」（file mark，藍色 ▼）。開檔時它在最前面；Write to Text File 從 ▼ 開始寫，寫幾個字元它就往後移幾格，寫到的地方原本有字就蓋掉。一格是一個位元組，換行 \r\n 佔兩格（CR、LF）。
